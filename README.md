# E-Commerce REST API

An e-commerce backend API built with Django REST Framework featuring products, collections, customers, and reviews.

---

## 🚀 Features

- Product management
- Collections API
- Customer profiles
- Product reviews
- Nested review routes
- RESTful API design
- Django ORM integration
- Authentication-ready structure

---

## 🛠 Tech Stack

- Python
- Django
- Django REST Framework
- MySQL
